DAS · Core

Un seul module gère toute la boucle de combat : attaques, sauvegardes, réactions, zones, auras, états. Plus d'ordre de chargement à respecter, plus de compatibilités à vérifier entre six auteurs, plus d'automatisation à importer sort par sort.

Obligatoire

DAS · Core

Le moteur de règles et de combat. Il gère toute la boucle de combat : plus aucun module ne se dispute vos clics.

  • Un clic au sol pour suivre un chemin, un clic sur un ennemi pour l'attaquer
  • Les attaques d'opportunité résolues avant le déplacement
  • Réactions et jets de sauvegarde sur l'écran de chaque joueur
  • Zones persistantes, concentration, états, auras
  • Règles de vision et de lumière : qui voit qui, Fouille, Perception passive

Demande Foundry V14 et dnd5e 6.0 ou plus récent. Ne modifie ni Foundry ni le système.

Demande Core

DAS · Combat UI

L'écran d'où l'on joue : une barre d'actions en bas, les portraits du groupe sur le côté, l'ordre des tours en haut.

  • Actions rangées par onglet, disposition gardée pour chaque personnage
  • Le niveau d'un sort se choisit dans un tiroir
  • Une action grisée dit pourquoi
  • Budget de déplacement, Foncer, et le chemin affiché avant de valider
Demande Core

DAS · Loot & Trade

Ce qui se passe après le combat : des corps à fouiller, des coffres à crocheter, des marchands avec qui marchander.

  • Trésor tiré à la première fouille, selon le facteur de puissance
  • Contenants verrouillés : clé, outils de voleur ou MJ
  • Vol à la tire, objets jetés au sol, morts relevés
  • Fenêtre de troc, marchands qui se réapprovisionnent
Autonome

DAS · Shadows & Ambience

Des jetons qui s'ancrent dans la scène. Purement visuel : rien n'est jamais écrit dans votre monde.

  • Ombres au sol, et ombres portées par les lumières et le soleil
  • Les créatures volantes flottent ; plus un jeton est haut, plus il paraît grand
  • Flou au-delà de la vision dans le noir
Demande BLFX Premium

DAS · Animations

Des animations Boss Loot pour les capacités que Boss Loot ne reconnaît pas seul, comme les sorts de haut niveau. Vos propres animations sont conservées.

Boss Loot est un module tiers payant, non inclus.

Installer

Coller un lien dans Foundry

DAS ne figure pas dans le catalogue de Foundry. On l'installe avec ces liens, puis les mises à jour arrivent par l'habituel Check for Updates de Foundry. Les mêmes liens marchent sur The Forge.

D'abord, installer Core

Dans Foundry, ouvrez Add-on Modules → Install Module, collez le lien en bas, puis Install.

Bon à savoir

  • L'interface existe en anglais et en français. D'autres langues peuvent être ajoutées : chaque module a un fichier de traduction.
  • Core propose trois niveaux d'automatisation dans ses réglages : Essentiel, Assisté et Complet.
  • Sauvegardez votre monde avant d'essayer DAS sur une campagne en cours.
  • Une question, un bug, une idée ? Rejoignez le Discord (salon #francais), ou ouvrez une issue sur la page GitHub du module.
